# Contributing to IdentityDNA Protocol

Thank you for your interest in IdentityDNA Protocol. This project is currently in an early Alpha research stage, and contribution processes will evolve as the project matures.

## How You Can Help Right Now

- **Review the specification.** Read `docs/specification/` and `docs/protocol/`, and open an issue if you spot a flaw, ambiguity, or security concern.
- **Discuss the design.** Conceptual critique — especially around the trust engine, entropy sources, and threat model — is very welcome.
- **Report security issues privately.** See `SECURITY.md` before opening any public issue related to a potential vulnerability.

## Contributing Code

Because the reference implementation is currently under a proprietary license (see `LICENSE.md`), code contributions require prior coordination with the author. Please reach out at **contact@agentflow-enterprise.com** before submitting substantial code changes.

## Contributing Documentation

Documentation improvements (clarity, typos, better examples) are welcome via pull request against the relevant file in `docs/`.

## Communication

For questions, proposals, or collaboration ideas, contact **contact@agentflow-enterprise.com**.
