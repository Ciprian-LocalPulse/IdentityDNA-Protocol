# Developer API

Describes the stable, documented API surface that third-party applications will use to integrate IdentityDNA Protocol without needing to understand its internal engines.

## Planned Surface (Draft)
- Session initiation endpoint.
- Identity Stream submission/update endpoint.
- Trust Score / access decision query.
- Session DNA issuance and revocation.

## Status
Not yet implemented. See `ROADMAP.md`, Phase 4.
