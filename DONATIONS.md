# Support IdentityDNA Protocol

IdentityDNA Protocol is an independent research project. If you find the idea valuable and would like to support its ongoing development — specification work, the reference implementation, and eventually an independent security audit — you're welcome to contribute.

## How to Donate

At this stage, donations are coordinated directly with the author. Please reach out by email to arrange a contribution:

**Contact:** contact@agentflow-enterprise.com

When reaching out, feel free to mention:
- Whether you'd like to support the project generally, or a specific phase of the [Roadmap](ROADMAP.md) (e.g., the security audit in Phase 8).
- Whether you'd like public acknowledgment as a supporter (optional).

## Why Support This Project

Meaningful authentication research takes time — protocol design, formal verification, reference implementations across multiple languages, and eventually independent auditing. Community support helps sustain that work and keeps the specification open for public review.

## Transparency

This project does not currently operate a public funding platform. All contributions are handled directly and acknowledged individually unless anonymity is requested.

Thank you for considering supporting this research.
